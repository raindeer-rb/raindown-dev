Bug reports and pull requests are welcome on [GitHub](https://github.com/raindeer-rb/raindown).

## Setup

After checking out the repo, install dependencies with:

```shell
bin/setup
```

Then run `bin/console` for an interactive prompt to experiment with.

## Testing

Run all tests with `bundle exec rspec`.

## VS Code extension

The extension is plain JavaScript with no dependencies or build step. Open the `vscode` folder in VS Code and press F5 to start a window with the extension loaded, opened on `../examples`.

## Guidelines

### AI

Please submit human-written code that is tested. AI will hallucinate and doesn't actually understand the code. AI is great for asking questions and generating benchmarks though.
